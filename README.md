# Traffic Signal Image Recognition System

## Overview
This project implements a **Traffic Signal Image Recognition System** that detects and classifies traffic signals from images.  
It is designed to recognize basic traffic light signals such as **Red, Yellow, and Green** using image processing and machine learning techniques.

This system can be useful in **intelligent transportation systems**, **autonomous vehicles**, and **road safety applications**.

---

##  Project Objectives
- Identify traffic signal images
- Classify traffic lights into Red, Yellow, and Green
- Apply image preprocessing for better accuracy
- Build a foundation for real-time traffic signal recognition
